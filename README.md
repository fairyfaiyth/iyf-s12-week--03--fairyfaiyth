# Week 03 Lab Assignment - Terminal and Git Basics

## Project Overview
This repository contains the completed exercises for the Week 03 assignment, covering core Unix terminal commands, project directory architectures, basic scripting, and local-to-remote Git workflows.

## Completed Tasks
* **Task 5.1 & 5.2**: Created standard nested directory structure and practiced essential file operations.
* **Task 5.3**: Analyzed repository structures using lookups (`find`, `grep`, `wc`).
* **Task 5.4**: Developed and configured an executable automated shell script (`new-project.sh`).
* **Task 6.1 & 6.2**: Practiced local version control workflows, branch isolated engineering, and clean linear merging.

## Automated Setup Usage
To quickly bootstrap a new web project structure with this automation script:
```bash
./new-project.sh <your-project-name>
\`\`\`
